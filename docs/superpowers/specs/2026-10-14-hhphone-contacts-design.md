# HHPhone 0.7.0 — карточка контакта, меню звонка, плавный журнал, тихое уведомление

Дата: 2026-10-14. Основа: HHPhone 0.6.0 (системный журнал и SMS, спека 2026-10-14-hhphone-native-dialer-design.md).

## Цель

Работа с контактами и журналом как в обычной звонилке: контакт — одна строка, нажатие на звонок открывает меню
действий, карточка контакта со всеми номерами, редактированием (имя, номера, фото) и блокировкой прямо в HHPhone.
Журнал листается без подтормаживаний. Постоянное уведомление не мешает.

## Решения пользователя

- Уведомление сервиса — «тихое» (вариант А): без значка в строке состояния, одна свёрнутая строка среди беззвучных.
  Сервис по-прежнему работает постоянно.
- Редактирование контакта — внутри HHPhone (вариант Б): имя, номера, фото; блокировка; не системный редактор.
- Нажатие на звонок в журнале не звонит, а открывает меню.

## Как сейчас (найдено в коде)

- «Контакты»/«Избранное»: строка на каждый номер (`HHPeopleTab`, `flatMap` по uris).
- Журнал: в каждой строке 3–5 линейных проходов по всем контактам (`hhName`, `HHAvatar`, иконка карточки), ничего
  не запоминается; ключ строки содержит минутный `tick` — раз в минуту весь список пересоздаётся.
- Карточка — экран baresip `ContactScreen`: контакты телефона там правятся только системным редактором; запись
  номеров в Android-контакт с ошибкой (`updateAndroidUri` перезаписывает все номера одним), поиск по имени без
  экранирования.
- Блокировка — правила baresip по подстроке на учётку; системный `BlockedNumberContract` не используется.
- Статус-уведомление идёт по каналу `low` (IMPORTANCE_LOW, общий со «звонок идёт»).

## Дизайн

### 1. Контакты одной строкой

- `HHPeopleTab`: строка на контакт (не на номер): фото/буква, имя, подпись — первый номер и «+N», если номеров
  больше одного; звёздочка. Нажатие — карточка контакта (п. 4). Коллеги — как сейчас (у коллеги один номер),
  нажатие — звонок.
- Поиск — по имени и любому номеру контакта.

### 2. Плавный журнал

- `HHPeople` (новый объект в `HHParts.kt`): кеш «собеседник → контакт/имя» по `peerKey`, сбрасывается при смене
  списка контактов (`BaresipService.contacts` — новый объект) и списка коллег. Поиск — `Contact.findContact`, затем
  `samePhone`, затем коллеги. `hhName`, `hhContact`, `HHAvatar` идут через кеш.
- В `HHPeopleTab`/карточке аватар строится по уже известному контакту (без поиска).
- Ключ строки журнала — без `tick` (`peer|last.stop`); минутный тик лишь обновляет подписи «N мин назад».
- `HHUiLogic.group` объединяет подряд идущие звонки одного номера по `samePhone` (+374… и 0… — одна строка).

### 3. Меню звонка (нижняя панель)

Нажатие на строку журнала открывает `ModalBottomSheet`:
- шапка: аватар, имя, номер, линия (SIM/станция), время;
- кнопки вызова по линиям (как на главной: SIM / HH …), кнопка «SMS»;
- пункты: «История звонков», «Карточка контакта» / «Создать контакт», «Скопировать номер»,
  «Удалить из журнала».
- «SMS»: для `tel:` — чат SIM (`sip:mobile@pstn`), для `sip:` — чат станции этой строки.
- «История звонков» — экран `hh_history/{peer}`: все звонки с этим номером (по `samePhone`), без группировки:
  направление, время, длительность, линия; нажатие на запись — то же меню без пункта истории.
- «Удалить из журнала» удаляет все звонки группы: из системного журнала по `_ID` строк (`HHLogGroup.ids`), иначе
  (журнал из `CallHistoryNew`) — `CallHistoryNew.remove` по времени.
- «Скопировать номер» — в буфер обмена, тост «Номер скопирован».

### 4. Карточка контакта (`HHContact.kt`, маршрут `hh_contact/{key}`)

`key` — `a<id>` (контакт телефона, `Contacts._ID`), `b<id>` (контакт baresip), `n<номер>` (новый, номер подставлен).

**Просмотр:** крупное фото, имя, звёздочка; список номеров (метка + номер, кнопки вызова по линиям и SMS);
кнопки «Изменить», «Заблокировать»/«Разблокировать».

**Редактирование** (тот же экран, режим правки):
- имя;
- номера: изменить, удалить, добавить (номер + тип: Мобильный/Домашний/Рабочий/Другой);
- фото: выбрать из галереи (`GetContent image/*`), удалить;
- «Сохранить» / «Отмена».

**Запись контакта телефона** (`HHContactStore`):
- читаются строки `Data` контакта (`CONTACT_ID = id`): `_ID`, `RAW_CONTACT_ID`, `MIMETYPE`, `DATA1`, `DATA2/3`;
- основной сырой контакт — тот, у которого строка имени (иначе первый);
- изменения — одной транзакцией `applyBatch`: номер изменён → `update` по `_ID`; удалён → `delete` по `_ID`;
  новый → `insert` в основной сырой контакт; имя → `update` строки `StructuredName` по `_ID`
  (`DISPLAY_NAME`, части имени очищаются — провайдер разберёт сам);
- фото → `RawContacts.DisplayPhoto` основного сырого контакта (`openAssetFileDescriptor("rw")`, JPEG ≤ 720 px);
  удаление фото — `delete` строк `Photo` контакта;
- новый контакт — сырой контакт без аккаунта (память телефона) + имя + номера (+ фото).
- Разница «было → стало» по номерам — чистая функция `HHUiLogic.numberOps(old, new)` (JUnit).
- Контакт baresip (режим «both»): `Contact.updateBaresipContact` / `addBaresipContact`, фото — как в baresip
  (`<id>.png`).
- После сохранения — `Contact.loadAndroidContacts` + `contactsUpdate` (наблюдатель контактов тоже сработает).

**Блокировка** (`HHBlock`): системный `BlockedNumberContract` — блокируются все номера контакта; разблокировка —
снимает их. Доступна, когда `BlockedNumberContract.canCurrentUserBlockNumbers` (HHPhone — звонилка или
SMS-приложение); иначе кнопка скрыта. Системная блокировка сама отсекает SIM-звонки и SMS; для станции
`BaresipService.isBlocked` дополнительно проверяет `BlockedNumberContract.isBlocked(номер)` — звонки и сообщения
через станцию с заблокированных номеров отклоняются как сейчас (486, запись в «Заблокированные»).

**Откуда открывается:** строка в «Контактах»/«Избранном», меню звонка, иконка карточки в строке журнала
(новый контакт — `n<номер>`), «Добавить контакт» на клавиатуре (`n<набранное>`).

### 5. Тихое уведомление

- Новый канал `com.tutpro.baresip.plus.status` (IMPORTANCE_MIN, без звука, без значка): статус-уведомление в
  покое. Канал `low` остаётся для «звонок идёт». Важность существующего канала кодом не понизить — поэтому новый.

### 6. Мелочи из ревью 0.6.0

- Звонок станции на номер другого сервера: в `CallLog.NUMBER` пишется `user@домен`, если домен собеседника не
  совпадает с доменом учётки; при чтении такой номер даёт `sip:user@домен`.
- Строки журнала других приложений (не SIM, не HHPhone — по `PHONE_ACCOUNT_COMPONENT_NAME`) — без пометки «SIM»,
  перезвон — обычный выбор линии.
- Удаление SMS без роли SMS — тост «Удалять SMS может только SMS-приложение по умолчанию».
- Запись входящего SMS в базу — в фоновом потоке.
- Код `PendingIntent` отправки SMS — номер строки базы + номер части.

## Чистая логика (JUnit, `HHUiLogic`)

- `numberOps(old: List<HHNum>, new: List<HHNum>): List<HHNumOp>` — update/delete/insert по `_ID`.
- `callLogEntry(..., component)` — SIM / станция / другое приложение; номер с `@` → `sip:` полностью.
- `callLogNumber(peerUri, aor)` — `user` или `user@домен` для записи.
- `group` — объединение по `samePhone`, `ids` строк группы.

## Проверка

- JUnit на всю чистую логику.
- Эмулятор `HHPhone_Test`: контакт с тремя номерами — одна строка, карточка показывает все; правка имени, номера,
  добавление/удаление номера, фото — сохраняются (видно и в системных «Контактах»); новый контакт из журнала;
  блокировка — входящий `adb emu gsm call` с заблокированного номера отклоняется системой, SMS не приходит;
  разблокировка; меню звонка — все пункты; удаление из журнала; история звонков номера; прокрутка журнала
  на 200+ записях без подтормаживаний (вставить записи в CallLog); статус-уведомление — без значка в строке
  состояния, звонок по-прежнему с уведомлением.
- Выпуск 0.7.0 (versionCode 12).

## Вне объёма

- Удаление контакта, объединение/разделение контактов, несколько адресов e-mail.
- Правка контакта, привязанного к аккаунту «только для чтения» (Exchange и т. п.) — правки провайдер отклонит,
  покажем ошибку.
