# HHPhone 0.5.0 — новый интерфейс звонилки

Дата: 2026-10-13. Статус: утверждено пользователем в диалоге (решения ниже — его ответы).

## Цель

HHPhone заменяет системную звонилку (SIM + станции HHPBX). Нынешние экраны baresip+ пользователь назвал «ужасными».
Образец — True Phone (com.hb.dialer.free): входящий с фото и ползунком, журнал + большая клавиатура, разговор с сеткой
кнопок и кнопкой «Завершить». Оформление — HHDesign (бордо #7A0C2A, графит Fluent 2, уже в Colors.kt/Theme.kt),
светлая и тёмная тема, языки ru/hy/en.

## Решения пользователя

1. Новые экраны в наших файлах `HH*.kt` (Compose); логика звонков baresip (Call, UserAgent, Api, BaresipService,
   InCallService) не переписывается; файлы baresip меняются точечно — только подключение новых экранов.
2. Линия при наборе — **две кнопки вызова**: «SIM» и станция («HH 101»), у станции точка состояния регистрации.
3. Чаты (SIP MESSAGE) — **четвёртая вкладка**; учётки, настройки, QR, выход — в меню «⋮».
4. Экраны звонка **следуют теме**: светлая — светлый фон, фото/буква в большом круге, тёмный текст; тёмная — фото на весь
   экран с затемнением (как образец). Без фото — буква на бордовом градиенте (тёмная) / в бордовом круге (светлая).
5. «Контакты» = контакты телефона + раздел **«Коллеги»** — номера станции, список отдаёт HHPBX (1.11.0).
6. Кнопки разговора: **«Перевести», «Пауза», «Без звука», «Добавить», «Динамик», «Клавиши»** + «Завершить».

## Экраны

### Главный (route "main")

- Вкладки сверху: «Избранное», «Телефон», «Контакты», «Чаты»; активная — бордо.
- **Телефон**: журнал звонков (SIM — из системного CallLog, SIP — CallHistoryNew baresip), сгруппирован по собеседнику
  подряд идущими звонками; строка: кружок (фото или первая буква, цвет по хэшу имени из приглушённой палитры),
  имя/номер, счётчик звонков в группе, стрелка направления (входящий/исходящий/пропущенный — красный), длительность,
  тип номера (из контакта: «Мобильный»…) или страна по коду, время («16:06», «37 мин назад», «вчера»). Нажатие —
  вызов по линии последнего звонка; кнопка справа — карточка контакта / «Добавить».
- Клавиатура снизу (сворачивается при прокрутке журнала, разворачивается кнопкой): цифры крупно, буквы под ними
  (латиница + кириллица), долгое «0» — «+», долгое «1» — голосовая почта станции. Над клавиатурой — набранный номер
  и подсказки из контактов/коллег по цифрам. Внизу: «Добавить контакт», **две кнопки вызова** (SIM | станция), «⋮».
  Если станций несколько — вторая кнопка открывает выбор; если SIM нет — одна кнопка станции, и наоборот.
- **Контакты**: поиск; раздел «Коллеги» (номер + имя со станции, кэш); контакты телефона (READ_CONTACTS).
- **Избранное**: контакты со звёздочкой (starred) + коллеги, отмеченные звёздочкой в HHPhone.
- **Чаты**: список чатов baresip в новом оформлении; сами экраны чата — прежние.
- Меню «⋮»: Учётные записи, Настройки, QR (для админа), Выход — как в 0.3.2.

### Входящий вызов

- Сверху «Входящий вызов» (или «… через HH 101» / «через SIM»), имя, номер, регион/тип.
- Ползунок внизу: круг по центру, влево — «Отклонить» (красная сторона), вправо — «Ответить» (зелёная).

- Работает поверх блокировки (полноэкранное уведомление уже есть в 0.4.x).

### Разговор

- Имя, номер, таймер (или «Вызов…», «На удержании»).
- Сетка 2×3: Перевести (выбор из коллег/контактов/набора → перевод: SIP — REFER baresip, SIM — недоступно, кнопка
  неактивна), Пауза (удержание), Без звука, Добавить (второй звонок; при двух — «Переключить» и «Объединить» если
  поддерживается), Динамик (и выбор Bluetooth, если подключён), Клавиши (DTMF).
- Строка второго звонка сверху, если есть. Внизу — красная «Завершить».

## HHPBX 1.11.0: список коллег

- `POST /app/hhphone/directory.php` (без сессии панели), поля user, domain, pass — проверка как `push_auth`
  (пароль SIP номера, только включённые номера), тот же счётчик неудач `fail_count` (10 с IP за 15 мин → 429).
- Ответ: `{"ok":true,"items":[{"n":"200","name":"Ресепшн"}, …]}` — включённые номера своего домена:
  `effective_caller_id_name` или `description`; свой номер телефон скрывает сам.
- Только свой домен; номера других доменов не отдаются никогда.
- HHPhone: запрос при старте и не чаще раза в сутки, кэш в prefs, при недоступности станции — кэш.

## Проверка

- Unit (JVM): группировка журнала, буква/цвет кружка (армянская/кириллица/латиница/цифры), выбор кнопок линий
  (SIM/станции), разбор ответа directory.php, форматирование времени «37 мин назад».
- HHPBX: t_hhphone.php (выборка коллег), VM-сценарий: свой домен, чужой домен, неверный пароль, 429.
- Снимки всех экранов в светлой и тёмной теме (эмулятор HHPhone_Test), проверка на S24: SIM и станция, входящий на
  блокировке, перевод звонка между 101 и 100.

## Не делаем (YAGNI)

Ответ сообщением, запись разговора и видео на экране разговора (остаются в baresip-меню), определение оператора
по номеру, собственная база геокодов.
